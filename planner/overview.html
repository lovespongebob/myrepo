The Weekly Planner · Overview

A sheet you refill every week can become a small tool.

This page explains the idea behind a weekly planner I made: the problem it solves, what it does, and the design choices that made it useful for more than one person.

The problem

The Monday routine nobody chose

Many weekly plans live in a spreadsheet that gets copied, emptied and filled in again every week. The work is small each time, but it repeats forever, and the old version is gone once it has been overwritten.

After
One fixed place to enter work. Set up once, used every week.

Every week stays on record, and each new week starts with last week's unfinished work already in hand.

What goes in

Eight fields, in the order people think

Each task is entered in the same order every time. Only the task name and the creator's name are required; everything else is optional, including the due date.

1Created by 2Project 3Task 4Owner 5Status 6Due date 7Related item 8Notes
What it does

Less retyping, more reporting

Three statuses, counted for you

Not startedIn progressDone

The weekly overview counts each status for the whole group and for each person, and updates the moment a task is ticked off.

A weekly report that writes itself

Tasks are grouped by owner and by status, with each person’s progress note alongside their tasks. The text is ready to paste into an email or a team chat.

Sorting you can predict

Tasks sort by due date. Tasks without a date show as ———, and each person chooses whether they sit at the top or the bottom.

Export and reopen

The whole plan can be saved as a file and opened again later, with every field intact, so there is always a copy outside the tool.

What I learned

Three design decisions

01

The person who writes a task is often not the person who does it

The planner started as a personal tool. Once other people joined, it needed two separate fields for every task, because people regularly write down work that someone else will do.

Created by · who wrote it downOwner · who will do it
02

Owners don't need an account

An owner can be anyone: a colleague, a partner, a contractor, or someone who never opens the planner. People type names the way they say them, and the planner suggests names already used so spellings stay consistent.

03

Every field has to earn its place

Each field was kept only if someone would read it in the weekly report. Anything nobody would read was left out.

Before trusting it

Three checks, with made-up data first

Before any real work went in, the planner had to pass three quick tests using example tasks. The third one caught a real bug.

1

Leave a due date empty

Save a task with no date.

Then check the sorting.
2

Mark a task done

Tick one task off the list.

Then check the weekly report.
3

Export, then reopen

Save the plan as a file and open it again.

Then check every field came back.

Try it with your own weekly sheet

If your team refills the same sheet every Monday, three steps are enough to start.

  1. Pick the one sheet you recreate every week.
  2. Keep only the fields people actually read, and drop the rest.
  3. Test with fake data before anyone trusts it with real work.
